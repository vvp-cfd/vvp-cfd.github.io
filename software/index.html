    Software

    I develop and maintain numerical software for computational fluid dynamics. The main line of work is the LS-STAG family of immersed-boundary / cut-cell solvers; the open-source cfd-vv-suite project grew out of the need for reproducible verification and validation.

    LS-STAG-3D

    LS-STAG-3D is the 3D extension of the LS-STAG immersed-boundary method for incompressible flows with moving bodies of arbitrary shape, including rotors and other coupled FSI problems. The code repository is named LS-STAG-3D_parallel. The numerical method implemented there is LS-STAG-3D, which I developed and continue to advance.

    Scope:

    • 3D cut-cell discretisation with a level-set representation of arbitrary moving bodies
    • staggered Cartesian meshes
    • ALE mesh motion and an incompressible Navier–Stokes solver with fluid–structure interaction
    • coupled aeroelastic and hydroelastic problems

    Repository: github.com/vvp-cfd/LS-STAG-3D_parallel
    Visualizations: SciVis

    Earlier members of the family include 2D solvers for turbulence, viscoelastic and generalized Newtonian fluids, as well as domain-decomposition and GPU versions. Their registrations are listed below.

    cfd-vv-suite

    An open test suite for verification and validation of CFD codes. It provides a standardised, reproducible, solver-agnostic workflow: the user supplies results as CSV, and the CLI compares them with reference data, computes error norms and generates reports.

    • 58 cases: 51 built-in and 7 imported
    • verification and validation cases for incompressible, compressible, non-Newtonian, turbulent and moving-body flows
    • OpenFOAM integration and Docker images
    • Python package cfdvv (v0.6.0 on PyPI)

    Links: GitHub · Documentation · PyPI 0.6.0 · Docker · Zenodo DOI

    beamer-template-kit

    A commented LaTeX Beamer class for presentations. Colours, fonts, icons, slide layout, blocks, tables and animations are configured in one file.

    Links: GitHub · Habr article · Zenodo DOI
